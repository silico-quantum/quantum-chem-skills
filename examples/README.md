# Examples

Saved examples use benzene (C6H6) as the reference molecule. The files record
a macOS arm64 environment from 2026-03-27; they are not regenerated by the
current structural CI checks.

| Multiwfn | 3.8 |
| xyzrender | Not recorded |

## pyscf/

B3LYP/cc-pVDZ calculation on benzene (D2h symmetry).

### Results

| Property | Value |
|----------|-------|
| SCF Energy | -232.2627 Ha |
| HOMO (B3g) | -6.8956 eV |
| LUMO (B1u) | -0.1571 eV |
| HOMO-LUMO gap | 6.7386 eV |

### LR-TDDFT Excited States (B3LYP/cc-pVDZ)

| State | E (eV) | λ (nm) | f |
|-------|--------|--------|---|
| S1 | 5.4951 | 225.7 | 0.0000 |
| S2 | 6.2307 | 199.0 | 0.0000 |
| S3 | 7.2776 | 170.4 | 0.5737 |
| S4 | 7.2781 | 170.4 | 0.5733 |
| S5 | 7.4489 | 166.5 | 0.0000 |

### Other Results
- **Density Fitting**: -232.2627 Ha, diff = -0.0001 eV from canonical
- **PCM (cyclohexane, ε=2.0)**: -232.2630 Ha, shift = -0.0083 eV
- **NTO** (S3 in the recorded LR-TDDFT block): leading weights 0.4819 and 0.4805, indicating two near-equal leading NTO pairs

> **Recorded-output caveat:** the custom `--- Mulliken ---` summary in
> `benzene_output.log` indexed AO populations as if they were atomic charges.
> Use PySCF's preceding `** Mulliken atomic charges **` block, or the corrected
> scripts in this repository, for atomic charges.

### Files
- `benzene_output.log` — Full calculation output
- `benzene_homo.cube` — HOMO orbital cube file
- `benzene_lumo.cube` — LUMO orbital cube file

## molecular-sampler/

Molecular sampling from benzene cluster (12 molecules, 144 atoms).

### Results
- 12 monomers extracted
- 5 dimers, trimers, tetramers, pentamers sampled (distance-sorted nearest neighbors)

### Files
- `benzene_cluster_N12.xyz` — Input cluster
- `monomers/` — 12 individual benzene molecules
- `dimers/` — 5 nearest-neighbor pairs
- `trimers/` — 5 trimers
- `tetramers/` — 5 tetramers
- `pentamers/` — 5 pentamers
- `sampling_summary.txt` — Sampling statistics

## xtb-cluster-md/

GFN-FF molecular dynamics of benzene cluster (8 molecules, 96 atoms, 300 K, 5 ps).

### xTB MD Settings
- Method: GFN-FF
- Temperature: 300 K
- Time: 5 ps, step: 2 fs
- NVT ensemble

### Generated Animations
| File | Description | Frames |

### Files
