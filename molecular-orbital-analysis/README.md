# Molecular Orbital Analysis

This directory provides an Agent Skill for planning molecular-orbital analysis
with PySCF, Multiwfn, and PyMOL-compatible visualization outputs. It does not
bundle a standalone analysis program or example input data.

Read [SKILL.md](SKILL.md) for the supported workflow, prerequisites, output
formats, and validation checks. Install the underlying scientific programs
separately and verify their versions before applying the workflow to research
data.
